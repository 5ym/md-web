# md-web

CodeMirror 6でmarkdownを入力しそれをgithub風の表示に変換します。  
エディタは隠せるので、フルスクリーンでスライドなどに利用できます。  
そのまま印刷もしくはpdfに変換でき、CSSエディタで印刷用のスタイル（`@page`など）を調整できます。

| ボタン | 動作 |
| --- | --- |
| `CSS` | CSSエディタの表示切り替え。書いたCSSはプレビューと印刷に反映されます |
| `←` / `□` | エディタの表示切り替え（プレビューをフルスクリーンに） |
| `↓` | 印刷 / PDFに保存（`Ctrl` / `Cmd` + `P` でも可） |

ビルド不要の静的サイトです。依存はimportmap経由でCDNから読み込みます。
